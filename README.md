# Четырёхмерный куб

Страница о тессеракте. Сначала — что это за фигура и как она вращается в центральной проекции. Затем — как четырёхмерный куб собирают из отрезка, квадрата и куба. В конце — почему на рисунке один куб оказывается внутри другого, а ровные грани становятся трапециями и усечёнными пирамидами.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:4721](http://127.0.0.1:4721).

Остановить сервер: `Ctrl+C`. Сборка без сервера разработки: `npm run build`, затем `npm start`.
